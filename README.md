# Agent Coding Standards CLI

`acs` generates `CODING.md` from selected, versioned profiles in a GitHub repository.
Rules versions are independent of the CLI version.

## Installation

Requires Git and access to the rules repository. Prebuilt binaries target Linux x64.
Download `acs` and `SHA256SUMS.txt` from [Releases](https://github.com/opendreamnet/agent-coding-standards-cli/releases), then:

```bash
sha256sum -c SHA256SUMS.txt
sudo install -m 755 acs /usr/local/bin/acs
```

## Usage

```bash
acs init --profiles typescript html
acs sync
acs update --dry-run
acs update
acs check
```

- `init`: create the file; use `--version X.Y.Z` to pin a specific rules version, otherwise the highest stable version is selected. Existing files are never overwritten.
- `sync`: regenerate with the pinned version and commit, including after editing `profiles`.
- `update`: adopt the highest stable rules version, preserving profile selection.
- `check`: verify without writing; return a nonzero exit code on divergence or errors.

Use `-C <directory>` to target another project. Replacements show a diff and require confirmation; `--yes` authorizes them without prompting. `--dry-run` previews writes.
HTTPS uses Git credential helpers; add `--transport ssh` to use SSH authentication.

## Configuration

The default rules repository is [opendreamnet/agent-coding-standards](https://github.com/opendreamnet/agent-coding-standards). Override it during initialization with `--repository owner/repo`.
Rules repositories must publish stable `vX.Y.Z` tags and `profiles/<name>.md` files.

```yaml
---
# Generated by acs. Project-specific exceptions belong in AGENTS.md.
repository: opendreamnet/agent-coding-standards
version: 0.1.0
revision: 4124f93373358654b25dd4f295f9d77cd8fb6b95
profiles:
  - typescript
  - html
---
```

Only declared profiles are included, in their declared order. Moved tags are rejected.
The body is generated; keep project-specific instructions and exceptions in `AGENTS.md`, and tell agents to consult `CODING.md`.
The CLI preserves unrelated front matter, never edits `AGENTS.md` or the consumer's Git repository, and never commits or pushes. Downloads use temporary storage, not a persistent cache.

## Development

Requires Node.js LTS (24+), pnpm, Git and Clang. UPX is required only for compression.

```bash
pnpm install --frozen-lockfile
pnpm dev --help
pnpm test
pnpm test:native
pnpm build
pnpm build:compress
```

The executable is written to `build/acs`. Run `pnpm typecheck`, `pnpm lint` and `pnpm prettier:check` before submitting changes.
